📦 WHAT'S INCLUDED:
  ✅ Multi-stage Docker build (Node 20 + nginx)
  ✅ pnpm@9.15.4 package manager
  ✅ Vite production build
  ✅ nginx web server with gzip compression
  ✅ Health checks & monitoring
  ✅ ESM support (type: module)
  ✅ Security headers enabled
  ✅ SPA routing (fallback to index.html)
  ✅ Optimized caching (1 year for assets)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🚀 QUICK START (3 commands):

  1. Build and start:
     docker-compose up -d

  2. View logs:
     docker-compose logs -f shof-tv

  3. Stop:
     docker-compose down

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🌐 ACCESS:
  Main App:     http://localhost:8080
  Health Check: http://localhost:8080/health

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📋 USEFUL COMMANDS:

  # Rebuild after code changes
  docker-compose build --no-cache
  docker-compose up -d

  # Check container status
  docker ps
  docker inspect shof-tv-app

  # View real-time stats
  docker stats shof-tv-app

  # Enter container shell
  docker exec -it shof-tv-app sh

  # Clean up everything
  docker-compose down
  docker system prune -a

🔧 TROUBLESHOOTING:

  Port 8080 in use?
  → Change port in docker-compose.yml:
    ports: - "3000:80"

  Build fails?
  → Clear cache: docker builder prune -a
  → Rebuild: docker-compose build --no-cache

  Container won't start?
  → Check logs: docker logs shof-tv-app
  → Health: docker inspect shof-tv-app
